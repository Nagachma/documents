Docker need to be install as a part of developing application , developers are developing in different env like windows,linux,mac so when try to run the application in different env compatability issues are occuring 


to overcome this they are installing docker engine and and creating container and that container is same for all,

to run that container a docker image will be created and all linux machine , windows machine , mac os developers will develop the code on same environment

whereever deploy the code there also docker engine and container will be installed 

now the code will run seamlessly on all flatforms

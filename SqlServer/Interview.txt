1) what is normalization

Normalization is a database design technique to remove redundant data

(ex: redundant data in a table like India , Ind, Austrilia , Aus )

Normalization can be implement by splitting one table into two tables, one with reference(master data) and other transaction data

2) what is denormalizaion 

Denormalization is a database design technique to improve search performance, here we merge the tables and ok to have duplicate data 

3) what is oltp(online transactional processing) and olap(online analytical programming) ?

in high volumes milions of records database people will create 2 databases one is OLTP(for Insert , update , delete) and another is OLAP(for Select , read)

in OLTP we can go for Normalization to avoid redundancy and in OLAP we can go for denormalization to improve search performance

4) what is 1st ,2nd,3rd Normalization Forms 


1st Normalization : A table in the first normal form when the columns have atomic values(morethan one value in single row) or it should not have repeating groups


2nd Normalization : First normal form should be satisfied , All non-key columns should be fully dependent on the primary key

3rd Normalization : all 1st and 2nd normal should be satisfied , No transient dependency should be present

6) differnce between Char and Varchar

Char is fixed and Varchar is Variable length 

  
for char if we have char(aa) or char(aaa) if we give length 3, it will take 3 char for both aa and aaa

for varchar if we have varchar(aa) or varchar(aaa) if we give length 3, it will take 2 char for  aa and 3 char for aaa
